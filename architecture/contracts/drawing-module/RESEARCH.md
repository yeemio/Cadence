## 0. 结论摘要（先读这节）

1. **源系统没有图文档管理**。73 份源开发文档全量 grep：`图号` 434 处命中、`图纸`/`图档`/`电子图`/`受控` **零命中**。源系统形态 = **通用附件表（bizFile，MinIO/OSS+预签名下载）+ 图号字符串列（drawing_no varchar(100)）贯穿引用**，无图纸库、无版本受控、无变更通知、无查看权限概念。图文档管理（版本化/保密/留痕）**全部是我方基线**（0920 定制项 #37"工艺图纸管理"），不是源系统需求还原。
2. **我方 drawing 域已是"合同冻结+实现+接线+20 测试在役"状态**（RREQ-WO-021~028 八条全已实现）：append-only 修订链、钉版引用不漂移、保密两级+同形 404、查看留痕不变量（fileRef 唯一取得路径）、变更通知游标、按工作令图纸清单三态、留痕审计。API 面完整，**缺的只是呈现面**（D-WO-05）。
3. **呈现面在途 writer 正在收口**（未提交工作区实态）：图纸库页/审计页/工作令入口卡片/menu+assembly 注册已落盘，自登记"不做"三项（全库索引端点/上传通道/租户许可配置面），测试文件尚未落盘。**P0 = 校准在途范围并验收，不扩盘**。
4. 真实缺口集中在三处（全部 P1/P2，均有登记锚点）：①变更通知→挂接方待办**未接线**（合同 §4 承诺方向，全仓 grep 零消费实证）；②图纸与工艺路线（baseline Routing 同以图号为键）**互链未裁定**（m3-03 §10 开放问题）；③水印/下载控制/短时签名 URL 属实施层（22 册 INT-005 HMAC 短时引用机制**已实现可复用**，真 SDK 预签名归部署期 INT-007）。
5. 行业惯例对照：我方已覆盖机加工 MES 图文档管理的高价值核心（版本受控/钉版引用/保密留痕/变更通知）；水印、打印控制、在线 CAD 预览、PDM/PLM 集成等属"按需高阶"，合同已明示禁入 CAD 解析（ADR-0007），维持不做。

### 1.4 有无独立图文档管理需求：没有；两条弱线索

### 4.2 分阶段结论（详见 CONTRACT.md）

- **P0 呈现面收口**＝校准在途线：完成 drawing-pages 测试落盘+code-reviewer 验收+四问式对照 RREQ-WO-038 验收口径；唯一裁量项=移动查看是否补最小入口（建议登记不补，沿 M5 裁定）。零后端改动。

### 4.3 不做清单（过度工程防线）

1. **在线 CAD 解析/预览渲染**——合同禁入（ADR-0007 依赖树教训），预览=PDF/图片由 fileRef 解释。
2. **图纸借阅流转/受控章/纸质发放回收**——纸质时代遗产，单件流+数字化后无需求，源文档零命中。
3. **PDM/PLM 集成**——无客户需求；出现时=集成域（22 册）课题非 drawing 域。
4. **文件二进制上传通道进 drawing 包**——drawing 保持"版本化文档事实域"，字节归 INT 附件域（ObjectStoragePort 先例）；fileRef 引用即接口。
5. **工作令附件域反向侵入**——附件挂接事实/计数归 workorder（88 数据源），drawing 只管图纸本体（m3-03 §1 分工铁律，两侧零 import 维持）。
6. **下图统计口径迁移**——口径归 metric-pack（20 册），drawing 只出修订事实；v1 附件计数口径不动，v2 由 Owner 点向后另立。
7. **drawingId 编码规则进类型**——合同明示"编码规则=数据约定不进类型"；连字符组成类型语义已在 14 册 listing 落位，不双写。
8. **钉版引用自动升级**——hasUpdate 只提示，升级是显式动作（合同钉版纪律）；不做"自动跟随最新版"。
