# ADR-0001 栈级零重合

状态：accepted（2026-10-23 Owner 定案，2026-10-24 入库）
来源：决策簿 V1.0 ADR-0001 / 交接文档 §3-§4

## 背景

Owner 未来创业（原话："跟现在系统重合的那些有可能产生争议的技术栈我们都不用"）。
现系统 = Java / SpringBlade + Vue2 / ElementUI + MySQL / MyBatis + 自研审批流。
重合 = 争议向量。

## 决定

全线异族选型：

| 层 | 选型 | 与现系统关系 |
|---|---|---|
| 后端 | NestJS + TypeScript（组合根在 apps/server，业务包纯净无框架依赖） | 异族 |
| 前端 | React 18 + shadcn/ui + Tailwind v4 + TanStack + Radix（refine 无头数据层） | 异族 |
| 数据库 | PostgreSQL 16 + Prisma（弃 MySQL） | 异族 |
| 状态机 | XState（九态工作令 + 审批流共用内核） | 代码全新 |

## 后果

- Java/JVM 出局：AI 施工全栈单语言效率最高、私有化部署轻（Node ~200MB vs JVM 2~4G）
- 任何引入与现系统同栈组件的提案默认拒绝，需先证明无争议可能
