# ADR-0002 清洁室纪律

状态：accepted（2026-10-23 Owner 定案，2026-10-24 入库）
来源：决策簿 V1.0 ADR-0002 / 交接文档 §5

## 背景

重建的合法性防线是清洁室，不是换栈。73 份雇主开发文档
（`AI/gitrep/sieracMes-AI/docs/开发文档/`）包含现系统实现细节，作为生成输入会引入侵权风险。

## 决定

四条纪律：

1. **零搬运**：不复制现系统任何代码、SQL、Mapper、配置、模板——含 blade-* 体系一切脚手架
2. **规格源切换**：AI 生成输入 = 独立产出的《功能清单拆解 V2》《工厂流程拆解》《状态机》+ 新写领域规格；
   73 份雇主开发文档禁用；字段口径从行为需求重述，不从原实现抄
3. **对账按行为等价**：新系统与活系统"同输入同输出"黑盒比对；不从原代码导出逻辑
4. **数据迁移照常**：数据归雇主，迁移数据 ≠ 复制实现

## 后果

- 字段级口径缺口用"行为需求重述 + 对账测试反推"补齐
- 施工与对账工具（~10 人日）是切换安全生命线，不可砍
- 审阅代码时凡出现疑似源自现系统的命名/结构，按违规处理
