# ADR-0005 双形态多租户

状态：accepted（2026-10-23 Owner 定案，2026-10-24 入库）
来源：决策簿 V1.0 ADR-0005 / 交接文档 §7；RLS 模式参照 crbnos/carbon（AGPL，仅模式参照，代码零接触）

## 背景

Owner 要求：同一代码可 SaaS 线上部署、可单租户私有化运行；且对应双定价
（买断 246k = 单租户私有化；订阅 54k/年 = 托管 SaaS）。

## 决定

- TenantContext 中间件贯穿全链：单租户 = 固定默认租户（零开销）；SaaS = PG 行级安全（RLS）+ Prisma extension
- 同一代码双部署 profile：docker-compose 单机 ↔ SaaS profile
- 租户身份从命令信封（tenantId）进入，不依赖环境推断

## 后果

- RLS 落地在 M4；M1 起所有表和信封都带 tenantId，避免返工
- 单租户形态的性能不能因 SaaS 能力付出可感知代价
