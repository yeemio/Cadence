# ADR-0007 复用优先与许可证纪律

状态：accepted（2026-10-23 Owner 定案，2026-10-24 入库）
来源：决策簿 V1.0 ADR-0007 / "复用与自研"页 / 交接文档 §8

## 背景

Owner 指令："不要动不动就完全自研，去找一下 github 有没有现成的仓库"。
GitHub 调研结论：TS 生态无整仓可用的 MES（carbon=AGPL 禁入；IMES 弃更；快格云后端 Python 不合）。

## 决定

- **复用**（平台件全复用）：refine / XState / casbin / ECharts / ExcelJS / pdfmake / html5-qrcode / Vite / Vitest / Playwright
- **自研薄层**：审批流配置(~10人日) / 多租户(~15) / 报表口径(~25，口径包=商业资产) / IM 适配(~12)
- **自研（清洁室）**：MES 领域模型(~155人日) + 施工对账(~10) + 基础层(~35)——无替代品且纪律要求
- **许可证白名单**：MIT / Apache-2.0 / BSD / PostgreSQL License；GPL / AGPL 全线禁入；
  "仅供学习"类禁；商业版功能禁
- **禁入清单**：crbnos/carbon 代码（AGPL，架构金矿可参照但零接触）；blade-* 体系；73 份雇主开发文档

## 后果

- 新增任何依赖先查许可证，不在白名单即拒绝，无例外
- kuaigeyun-mes 前端基础壳（Apache-2.0）2 人日 spike 后决定是否选择性复用（ADR 待 spike 补充）
