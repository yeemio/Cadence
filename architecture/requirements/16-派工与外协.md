# 16 · 派工与外协（DP）

版本：v1.0（2026-10-26 冻结）｜编写者：code-writer-pro GLM-5.3（agentId 见回传）｜域码：DP（dispatch + aftercare-claim）

## 1. 域定位与边界

**身份**：任务派发中枢——把工作令分解为到人到序（外协到供应商）的执行单，六类一体（零件/外协/装配/电气/售后/零工）共用一套四态状态机；售后报销（aftercare-claim）为售后单的财务延伸子域，随本域交付。

- **In（消费）**：工作令与齐套事实（KitCheck 只读）、工序与外协计价规则（baseline 只读）、零件清单行（外协工序来源锚点）、审批通过报工集（售后报销明细来源，经端口只读）、打印/IM 基础设施（端口）。
- **Out（产出）**：执行申报入口（reporting 挂有效派工单）、外协回厂来源事实（inspection 消费）、进度事实（workorder 上卷）、外协定价信号（costing 重算）、售后成本取数信号（A5 报表）、执行人待办（workbench）。
- **边界**：报工/审批/质检单据本体归 17（RQ）；配件申请归 18（IS）；工时汇总与成本归集归 19（HC）；在制工时汇总等报表呈现归 20（RP）；移动端入口归 21（MB）；打印渲染适配归 22（INT）。

## 2. 角色与场景

| 角色 | 权限码 | 场景 |
|---|---|---|
| 计划员/派工员 | `dispatch:write` | 六类建单（含齐套拦截）、开工、完工；桌面「派工管理」页 |
| 调度/班组长 | `dispatch:assign` | 派工到人（推送执行人待办） |
| 生产主管 | `dispatch:cancel` | 撤销草稿/已派工单（执行中起不可撤） |
| 查询角色（各级管理） | `dispatch:read` | 六类列表筛选、详情、按人/按序任务视图、进度事实 |
| 外协管理/采购 | `outsourcing:read` | 外协明细供应商维度查询、加工单打印数据与打印提交 |
| 财务/成本 | `outsourcing:price` | 外协单价补录（触发 costing 重算） |
| 售后负责人/财务 | `aftercare:read` / `aftercare:claim` | 售后报销查询与四费填报/编辑 |

- 桌面入口：派工管理页（菜单键 `dispatch`，apps/web/src/pages/dispatch/DispatchOrdersPage.tsx）、外协管理页（菜单键 `outsourcing-lines`，…/OutsourcingLinesPage.tsx）。
- 移动端：无独立移动派工页；移动报工页消费派工单（归分册 21）。小程序售后派工/报工差异 S7 亦归分册 21。
- 执行人被动接收：assign 产生 workbench 待办，开工/完工/撤销自动销账。

## 3. 业务对象与状态机

| 对象 | 说明 |
|---|---|
| 派工单 DispatchOrder | kind ∈ part/outsourcing/assembly/electrical/aftermarket/oddjob；零件单带图号×工序×工艺属性快照（材料/尺寸随单） |
| 外协明细 OutsourcingLine | 每行供应商×工序×数量；单价来源 lookup/manual/backfill，交期 promisedAt，可回锚零件清单行 |
| 售后报销单 AftercareClaim | 一张售后派工单一单；明细行 = 审批通过报工行快照（报工日期/售后人/审批工时冻结）+ 四费（食宿/交通/加班/其他） |

**状态机**（引 contracts/m2-drafts/04-dispatch.md §2，配置驱动可整体替换）：

```
draft ──ASSIGN──▶ assigned ──START──▶ executing ──COMPLETE──▶ done（终态）
  │                    │
  └──────CANCEL───────┘──▶ cancelled（终态；reporting 侧禁止再报）
```

- 外协单 done 联动回厂质检为**服务编排**（来源事实投递），非状态机节点。
- 售后报销无状态机：save 建单、update 重写四费，均带幂等与乐观锁。
- 分层（ADR-0010）：四态语义归 engine-flow 内核；六类 kind/命令/事件归模块 schema；齐套拦截 kind 集（默认装配/电气）为默认配置层。

**与源文档状态词汇映射**（口径对账用）：源文档四态「待下发/已下发/进行中/已完成」↔ 我方 draft/assigned/executing/done。差异两点以我方为准：① 源文档「撤销派工=已下发→待下发回退」，我方为 draft/assigned→cancelled 终态；② 源文档另有「撤销完工=已完工→进行中」，我方 done 为终态（差异 D-DP-05）。

**六类 kind 特有联动一览**（同一状态机之上的编排差异）：

| kind | 特有联动 |
|---|---|
| part | 图号×工序为机加工上卷键；工艺属性随单快照（DP-002/022） |
| outsourcing | 明细行集+实时取价+补录（DP-012~014）；done 投递回厂来源事实（DP-015）；加工单打印（DP-017） |
| assembly / electrical | 创建前齐套 fail-closed 拦截（DP-003）；工序为装配上卷键 |
| aftermarket | 唯一带报销子域的 kind（DP-018~020）；不进生产上卷 |
| oddjob | 描述性工作（标题或工序）；不进生产上卷；报工审批工时归集走 HC（§4.5） |

## 5. 业务规则与口径

1. **状态合法集**：五态五迁移（主干三 + 撤销二）；done/cancelled 终态；配置整体可替换（ADR-0010 条 2）。外协回厂、待办、进度上卷均为命令编排副作用，不扩状态集。
2. **齐套 fail-closed**：装配/电气建单读不到核查记录 = 拦截（非放行）；拦截证据（KitCheck id+刷新时刻）进创建事件载荷；拦截集经服务选项整体替换。
3. **外协取价口径（以我方为准）**：我方 = 工序基准价×(1+利润率万分比)（baseline 配置直接给价，marginPermyriad 万分比，对账锚 10000×1.15=11500 分）；源文档 = 计划工时/60×市场小时单价×(1+利润率%)。取舍：价格形态归 baseline（分册 12），dispatch 只消费 quote；如需对齐小时价×工时形态，改 baseline 规则不动本域。人工给定单价优先于取价；无规则落未定价不阻塞。
4. **完工与撤销**：doneQty ≤ quantity，缺省整单；撤销仅 draft/assigned。源文档「已下发→待下发」回退与「撤销完工」回退（D-DP-05）均未纳入现行合法集，如需启用走配置层扩迁移并保留终态语义审计。
5. **待办生命周期**：assign 建（执行人），start/complete/cancel 销该单 open 待办；来源 source=dispatch、refId=派工单 id。
6. **进度上卷**：仅 part（machining）与 assembly/electrical（assembly）进上卷且须有工序键；外协回厂走 inspection、售后/零工不属生产主线。
7. **售后报销**：一单一报销（(tenant, dispatchId) 唯一兜底并发）；行集恰合双向校验；四费 ≥0 默认 0（0 合法，区别于单价的 >0 语义）；行小计/报销合计读面计算不落冗余。
8. **命令纪律（全域通用）**：smes.command.v1 信封，operationId 幂等记账、expectedRevision 乐观锁；创建命令必 'initial'；违规载荷 400 语义不静默。
9. **与源文档不一致处的取舍汇总**（均以我方实态为准）：撤销=终态而非回退（S2）；完工触发质检而非下发即建（§6）；单执行人而非多操作工（多计划人缺口 D-DP-03）；外协无报工链路预留字段（回厂质检即进度来源，归 17）。

## 8. 开放问题（回传总控）

1. **权限码口径**：派发说明写 `outsourcing:read/write/price`，实态与合同 04-dispatch §5 均为 `outsourcing:read|price`（无 write，外协建单走 dispatch:write）——本册按实态登记，请总控核对派发笔误。
2. **D 编号撞号**：见 §7 末注，合流时统一处理。
3. **外协质检触发时机**：源文档下发即建质检单 vs 我方完工投递来源事实（§6）。已按我方实态书写；是否对齐源文档时机涉及 inspection 域，请 Owner 在分册 17 定稿时裁量。
4. **零工计划内/外 × 工时归集**：合同 04 open question 延续，随 D-DP-03 落位与 hours 对账时定。
5. **撤销完工（D-DP-05）与终态语义**：启用 done→executing 回退将突破现行「done 终态」口径与机器事件账本重放约定（重放一致性按合法集校验），需按 ADR-0010 配置换代整体迁移方案，建议 Owner 点向时再启动。
