# 15 · 仓储与库存（inventory）

版本：v1.0（2026-10-26 冻结）｜编写者：code-writer-pro（GLM-5.3，agentId 见交付回传）｜域码：IV｜验收记录：ACCEPT（code-reviewer GLM-5.3 agent_de0a2a99，2026-10-26）

## 1. 域定位与边界

**身份**：实物账中枢——在仓库/库位主数据之上维护「物料×仓库×库位」的现存量、预占与可用量，承载三类入库、三类出库、调拨移库、盘点调账与发货执行的出入库流水，是齐套判定与缺口核查的可用量事实源。

- **In**（消费什么）：
  - 仓库/库位主数据（本域自管，R4 裁决）；
  - 质检放行事实（inspection 判定放行后登记）；
  - 采购收货指令（listing 收货确认，receiptKey 幂等）；
  - 配件发料指令（workorder 配件审批通过，requestId 幂等）；
  - 预占请求（dispatch 派工 / 发料任务创建即预占）；
  - 完工入库（报工-质检闭环侧驱动 production-in）。
- **Out**（产出什么）：
  - 可用量（workorder 齐套判定、listing 缺口核查的事实源）；
  - 出入库流水与库存账（costing 材料成本归集、standardreports 库存报表族）；
  - ShippingConfirmed 事件（workorder 待发货→已发货联动）；
  - StocktakeAdjusted 调账留痕（审计取证）。
- **实现合同**：`architecture/contracts/m2-drafts/07-inventory.md`（v1.0，R1~R6 已裁定）；模块 `packages/application/src/inventory/`；PG 存储 `packages/business-store/src/inventory/pg-inventory-stores.ts`；内存实现 `in-memory-inventory-stores.ts`（同合同）。
- **非本域**：发料任务的创建/确认/撤销与快递单（18 册 IS 域——本域只承接其出库扣账与预占核销）；采购收货/退货单据本体（14 册 LP 域）；非标件「按图号/工作令」的进度型入库台账（13/17 册闭环侧，口径对照见 §5.4）；库存口径报表的呈现（20 册 RP 域）。

### 2.3 端到端场景走查

**场景 A · 采购件入仓（免检直入与质检放行两条路径）**

1. listing 收货确认 → 经收货端口联动入库存账（RREQ-IV-014，receiptKey 幂等），落默认仓/默认库位；
2. 来料需检路径：质检判定放行 → 放行事实登记（RREQ-IV-012），库管在桌面或移动端执行 inspection 入库（RREQ-IV-011），放行余量内多次分批入仓；
3. 入仓即现存量+库位余额上升、StockReceived 事件发出 → 齐套与缺口核查重算（§6.2）；
4. 库管在实时库存页核对可用量（RREQ-IV-004），在流水台账溯源来源采购单（RREQ-IV-031）。

**场景 B · 生产发料出仓（预占-核销全链）**

1. 发料任务创建 → 预占端口创建预占（RREQ-IV-008），可用量即时下降，现存量不动；
2. 拣货执行：发货任务按行执行（RREQ-IV-028），行级核销预占——现存量与预占同减、可用量不变；直扣行按物料×仓合并校验；
3. 任务确认（RREQ-IV-029）补承运/运单号 → ShippingConfirmed → 工作令「待发货→已发货」；
4. 未用余量经释放端口退回（可用量回升）；重发指令被幂等去重（RREQ-IV-013）。

**场景 C · 盘点调账**

1. 盘点员开单（RREQ-IV-024）圈定仓库范围，系统快照账面基线；
2. 持移动端到库位逐位录实盘（RREQ-IV-032/025），多轮覆盖、范围外拒绝；
3. 全部行已盘后提交差异进待审核；
4. 库管主管审核调账（RREQ-IV-026）：账面校到实盘、盘盈/盘亏流水落账、双口径差异留痕；实时库存与流水台账即时反映调账结果。

## 3. 业务对象与状态机

### 3.1 领域对象清单（品牌化 ID 见合同 §2；表形态见 inventory-stores.ts 头注）

| 对象 | 粒度 | 说明 |
|---|---|---|
| Warehouse / WarehouseLocation | 租户×仓库 / 仓库×库位 | 主数据（R4：归本模块）；(tenant, code) 唯一；仓库带默认库位 |
| StockAccount（库存账） | 物料×仓库 | 现存量 qtyOnHand + 预占量 qtyReserved——可用量恒等式的两个输入 |
| StockLocationBalance（库位余额） | 仓库×库位×物料 | 库位分布投影；FIFO 扣减读取序（createdAt 升序） |
| StockMovement（出入库流水） | 每笔收发存 | append-only 业务事实；来源单据引用 + 幂等键 sourceKey + 调拨关联 + 证据公共列 |
| StockReservation（预占行） | 租户×预占键 | 占用方单据引用（refType/refId）+ 剩余量 remaining |
| Stocktake（盘点单） | 仓库×单 | 四态机投影；lines=开单快照+实盘行（JSONB 载荷） |
| ShippingOrder（发货任务） | 单 | 三态机投影；lines=发货行（物料×数量×仓×预占键）；物流信息确认时补 |
| ReleaseFact（放行事实） | 质检单×放行阶段 | inspection→inventory 的登记账；(tenant, inspectionId, phase) 幂等 |

### 3.2 流水类别词汇（九种，方向由类别推导、数量恒正）

采购入库 purchase-in｜质检放行入库 inspection-in｜完工入库 production-in｜出库 issue-out｜发货出库 shipping-out｜调拨出 transfer-out｜调拨入 transfer-in｜盘盈 stocktake-gain｜盘亏 stocktake-loss。

### 3.3 状态机（engine-flow 配置驱动、可整体替换；状态集语义为内核，词汇为模块 schema）

| 状态机 | 迁移链 | 驱动命令 | 语义要点 |
|---|---|---|---|
| 盘点四态 | draft →(START)→ counting →(RECONCILE)→ reconciled →(ADJUST)→ adjusted（终态） | open / record(complete=true) / approve-adjust | reconciled=实盘完成待审核；record 录行不推状态机版本（行载荷事实非迁移） |
| 发货三态 | draft →(EXECUTE)→ executing →(CONFIRM)→ shipped（终态） | execute / confirm | 出库扣账在 EXECUTE（拣货执行即实物离位）；物流信息（承运/运单号）在 CONFIRM 补全 |
| 预占三态 | active →(consume/release)→ consumed / released | 端口 reserve/release + 出库核销 | 非状态机，条件推进账；终态键不得复用 |

入库/出库本身为**凭证**（append-only 流水+证据列承载），非状态机——源文档「待入库→已入库」中转单据形态是我方差异（D-IV-09）。建单类命令（盘点开单/发货执行）先落初始态投影行再驱动首次迁移——事件账本与投影对账，配置换代或账本损坏即拒绝继续（fail-closed）。

### 3.4 预占规则（合同 §2）

派工/发料任务**创建即预占**（跨域端口按预占键声明占用，可用量即时下降）；**完工入库/出库核销**（核销路径账面同减现存量与预占，可用量不变）；**未用释放**退回（部分或全量）。预占是可用量恒等式的唯一占用表达——同一物料的全部在途占用可枚举（预占行台账），齐套与缺口判定据此可信。

## 5. 业务规则与口径

### 5.1 可用量口径：我方恒等式 vs 源文档「结存+预占」双列

源文档（出入库和库存 §1.2/§3.2）以物料维度三个存储数量表达：总量（ALL）、可用（KY）、预占（YZ），入库按「有无工作令」分流——手工入库加 KY+ALL；采购入库（有工作令）加 YZ+ALL 不改 KY；预占另有明细表按来源单据精确写入/冲销。我方以恒等式统一：**可用量 = 现存量 − 预占**，可用量是机器计算派生值（非存储列），预占只经预占端口显式创建/核销/释放，任何写入路径不得绕过（service 校验 + PG 原子守卫双防线）。取舍说明：

1. 我方可用量按物料×仓库维度实时派生，杜绝源形态下 KY/ALL/YZ 三列漂移的可能（派生不可撒谎）；
2. 采购入库不自动转预占——需占用时由发料/派工侧显式 reserve（预占粒度由占用方声明，07-inventory.md §8 裁定，对账阶段以活系统行为反推）；
3. 源文档预占明细（按来源单据的占用台账）以我方预占行 refType/refId + remaining 承载，等价可达。

与源文档不一致处以我方实态为准（00-README §5 规则 2，依据 07-inventory.md v1.0 冻结裁决）。

### 5.2 出库三源与生产发料台账

源文档出库三源 = 手工出库 + 采购退货 + 生产发料，其中生产发料确认经 MQ「只写台账、不扣本模块库存」（发料模块自管占用账）。我方出库目的三类（production/parts/manual）统一扣账：生产发料占用一律以预占表达、发货/领料执行时核销——不设「只写台账不扣库存」旁路，避免同一物料两套占用账并存（发料侧快照 + 库存侧结存）漂移。采购退货出库在我方由入库退货流程（D-IV-05 待实现）落出库流水。

### 5.3 盘点双差异口径与实盘零值

调账流水（movement = 实盘 − 当前账面）与审计差异行（= 实盘 − 开单快照）分置：前者保证调账后账面=实盘（即使快照之后、审核之前又有收发动作），后者回答「盘点发现了多少差异」的审计问题。源文档 PRD 要求实盘>0（不允许填 0）；我方允许实盘=0（盘亏到零是合法业务结果），以我方为准。库位级盘点差异初版口径：全部落默认库位，库位级校正归对账阶段（合同注释裁定）。

### 5.4 非标件「进度型入库」与实物入库的分野

源文档《入库功能模块》的非标件入库是按图号/工作令的**进度型台账**（无库位、不写仓库库存；入库即回写订单/质检行/收货行/清单进度，已发料门禁禁止撤销）；《设备采购入库》同构（仅采购源、质检合格 Hook 驱动、无库位无退货）。我方将「实物入仓」统一为本域库存账（物料×仓库×库位），进度回写归 13/17 册的工作令闭环与质检放行链承载（放行事实→咬合入库即 RREQ-IV-011/012 的 inspection 路径）。三源入库的桌面呈现增强（页眉状态统计、下钻导航、外部带入 query、已发料门禁展示）归 RREQ-IV-011 锚点页与 D-IV-01/D-IV-03/D-IV-09 差异族。

### 5.5 数量精度与量纲

源文档数量 decimal(18,5)、按物料分类限小数位（原材料最多 5 位、其余正整数）、展示 2 位去尾零。我方数量为数值量，量纲遵循总纲 §5.9（时间分钟/金额分整数最小量纲）；分类化小数位约束暂不设为产品规则——如客户现场需要按物料分类的录入精度约束，属 11 册主数据域扩展项，不占用本域差异编号。

### 5.6 通用闸门与幂等层次

- 命令层幂等（operationId，被拒不占用、修正重发可重评）与来源层幂等（sourceKey = receiptKey/issueKey，命中回首次结果）双层去重，端口面联动指令的幂等键由调用方业务键承载（receiptKey/requestId）。
- 仓库/库位不存在拒绝；跨租户访问 fail-closed（全局约定 1）；出库/发货预校验后竞态窗口上抛数据级冲突（人工对账），不静默吞并。
- 状态机事件账本与投影行强对账：重放不一致（配置换代/账本损坏/中断写入）即拒绝继续。
- 主数据无状态机、无域事件（合同事件面最小集 5 个：StockReceived/Issued/Transferred/StocktakeAdjusted/ShippingConfirmed）——仓库定义的投影事实由投影行承载。

### 5.7 合同口径衔接与本册开放问题

合同 07-inventory.md §8 两个 open question 的现状：

1. **预占粒度**——现状：由占用方经预占键声明（发料任务行级键），本域不预设粒度；对账阶段以活系统行为反推后定，影响齐套口径。本册不新增裁定。
2. **负库存策略**——已裁定：默认硬拒绝、服务选项配置化（RREQ-IV-007）；盘点账实校正是唯一例外路径（实盘为准）。

| listing（采购收货） | InventoryReceiptPort 收货确认 | receivePurchaseStock 入账（receiptKey 幂等） |
| workorder（配件审批） | PartsIssuePort 配件通过 | issuePartsStock 出库（parts-{requestId} 幂等） |
| dispatch/发料任务 | StockReservationPort reserve/release | 预占创建/释放；发货执行行级核销 |
| workorder/报工闭环 | 完工入库指令 | stock.receive（production） |
| workorder（齐套）/listing（缺口） | availableQtyOf 批量查询 | 跨仓可用量读回 |

### 6.2 我触发谁（Out 事件/数据面）

| 事件/数据 | 消费方 | 联动 |

| StockReceived / StockIssued | workorder 齐套、listing 缺口 | 可用量变化重算信号 |
