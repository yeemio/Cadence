# 图纸 PDF 与工作令成本操作

更新：2026-11-04，适用于 PR #7 的成本/PDF 增量。这里说明产品页面的操作；隔离合成样本通过不代表客户真实图纸、真实成本历史或生产现场已经验收。

## 1. 先确认岗位权限

| 操作 | 需要的权限与前置 |
| --- | --- |
| 上传 PDF | 有效登录及附件写入权限 `attachment:write`，附件模块已启用 |
| 发布图纸修订 | 图纸发布权限 `drawing:publish`，正确图号、文件引用、保密等级和变更说明 |
| 查看修订和打开 PDF | 有效登录、图纸读取权限 `drawing:read`，所选保密许可覆盖目标修订 |
| 查看留痕列表 | 图纸审计读取权限 `drawing:audit-read` |
| 查询工作令成本 | 成本读取权限 `costing:read`；发布口径、重算及导出分别由获授权人员操作 |

上传成功不代表修订已经发布；能上传不代表能发布、阅读或查询审计。被拒时请管理员核对具体权限，不临时授予整组管理权限。保密许可仍是请求自声明，真实身份与保密等级尚未绑定，见[已知行为 A15](KNOWN-BEHAVIORS.md#a15-图纸保密许可是请求自声明v1-无租户许可配置面)。

## 2. 上传、发布和阅读 PDF

1. 从左侧「图纸文档」进入图纸库 `/drawings`，在列表点目标图号的「打开修订链」。首发新图号可先打开一条可见修订链，再在下方「发布新修订」填写新图号；若索引为空，由实施人员提供带新图号的入口，例如 `/drawings?drawingId=DWG-A01`。仅输入前缀检索不会创建图纸。核对发布表单图号与本次文件一致。
2. 在「PDF 文件（可选）」选择 PDF，点「上传 PDF」。原文件最大 **32 MiB**；上传后 `fileRef` 自动填入 `attachment:…`。不要把其他图号的文件引用填到这里。修改发布图号后文件引用会清空，需为新图号重新上传或填写匹配的引用。
3. 首发选择 `initial`；追加修订选择「追加」并填写当前链尾版本。选择保密等级、填写变更说明后点「发布修订」。版本由系统递增，不手工覆盖旧修订。若有人已追加版本，先刷新核对链尾，再提交；不要重复盲点。
4. 确认命令已生效，在对应图号的修订链核对新版本。选择允许的保密许可，点该版本的查看按钮，得到查看回执；这一步已产生留痕。
5. 在查看回执中点「打开 PDF（本次打开将留痕）」。确认阅读器标题的图号和版本、实际第一页画面与页码相符。用「PDF 上一页」「PDF 下一页」逐页阅读；用「−」「+」按 25% 调整，范围 **50%–200%**。加载或绘制期间按钮暂时不可用。
6. 点「关闭 PDF」结束阅读；重新打开会再次读取内容并留痕。翻页和缩放使用本次已加载的文件，不为每一页或每一次缩放新增查看记录。刷新或重新登录后，重新选择图号、许可和版本查看。
7. 有审计权限的人员从「查看留痕审计」按图号核对查看人、修订版本、许可和时刻。审计将元数据查看和 PDF 内容查看都记为 `viewed`，不能仅凭动作名区分两者。

短时签名图纸引用可在有效期内直接兑现**修订元数据**并留痕；它不是匿名 PDF 文件链接。产品内 PDF 阅读另需登录、图纸权限与本版许可。受控 PDF 不能通过普通附件下载入口绕过图纸门禁；浏览器已经取得的内容没有水印或防下载保护。

历史修订的外部 URL/存储键仍保留原样，本系统不会自动访问该地址，也不会自动把旧修订变成在线 PDF。有权人员应上传文件并发布**新修订**，原修订及其引用继续保留。

## 3. 工作令成本查询与快照

1. 从「成本与工时」进入「成本核算」`/costing`。在口径列表核对口径码和实际版本；仅由获授权人员按业务约定发布口径，不为消除对比提示而随意增版。
2. 在「工作令成本」填写同一条业务链的工作令 id、口径码，点「查询成本」。构成明细的「来源」用于追溯原业务来源，「数量 / 小时」用于核对用量；它不是金额。
3. 尚无所需快照且来源事实、口径都已准备好时，由有权人员点「重算」，确认操作已生效，再查询同一工作令。重算不能代替报工、采购、质检或入库事实，也不用于手工补造成本。
4. 核对「三分类汇总」「构成明细」「快照版本回看」。金额单位为**分**：`3000` 表示 30 元，`0` 是实际零值；「—」表示没有直接金额。工时明细保存小时量，按口径时薪在汇总与快照中金额化。例如合成样本 `0.5` 小时 × `6000` 分/小时 = `3000` 分，工时明细的金额仍可显示「—」。
5. 快照回看按口径及版本显示总额。同码两版本比较须填写两个**已存在的口径版本**；仅有 `standard` v1 时，请勿把默认 v2 不存在的提示当作 v1 成本丢失。合计等值的重复重算可能复用原快照及生成时刻，不代表命令未执行。

本轮修正的是显示字段，没有改变成本算法。材料或外协为 `0` 的合成样本不能证明所有成本类别的非零金额或真实历史都已验收。「导出快照（ExcelPort）」仍按既有导出通道执行，本次不承诺新增浏览器文件下载功能。

## 4. 失败时如何处理

| 页面现象 | 处理与交接 |
| --- | --- |
| 上传失败或提示文件无效 | 确认可读 PDF 且原文件不超过 32 MiB；保留文件名、大小和错误交实施人员，不改扩展名伪装文件 |
| 401／登录失效 | 重新登录，再核对图号、版本和许可；不要转交访问令牌 |
| 403／权限拒绝 | 管理员核对本次操作对应权限；上传、发布、阅读和审计是不同权限 |
| 图纸不可见／404 | 不存在与超保密许可可能同形；交图纸维护人员核对图号、版本、许可及附件关联，不据此猜测存在受限图纸 |
| PDF 打开失败 | 记录图号、版本和错误；若旧修订是外部引用，按第 2 节发布关联 PDF 的新修订；若文件损坏或已移除，交维护人员处理。读取门禁通过后即使后续文件加载失败，也可能已有一条查看记录 |
| 成本为空／版本不存在 | 核对工作令、来源、口径和现有版本；需要重算时由有权人员执行，不直接改历史行或为凑数据创建业务事实 |
