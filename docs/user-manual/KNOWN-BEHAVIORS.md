## A. 设计内行为

### A1. 附件与图纸的「引用」是短时效签名 token，token 即唯一凭证

- 附件下载引用默认有效期 **60 秒**（来源：`packages/application/src/attachment/attachment.service.ts` L31 `DEFAULT_DOWNLOAD_TTL_SECONDS = 60`）；图纸只读引用有效期上限 **600 秒**（来源：`packages/drawing/src/drawing-read-references.ts` L57）。
- 引用 URL 不挂登录门，持有 token 即可兑现（粘贴-转递语义）。图纸引用是否改为「必须登录」是待 Owner 裁定项（SP-5/裁-11，见 D 节）。
- 引用签发密钥的固化配置（SP-3：`SMES_ATTACHMENT_REF_SECRET` / `SMES_DRAWING_REF_SECRET`）**已随本轮未提交增量落盘**（server 组合根读取 + compose 透传 + `deploy/.env.example` 模板；来源：`apps/server/src/main.ts` L194-237）。语义：**未设置/留空 = 实例内随机生成 + 启动 warn 一行——服务重启后旧引用 URL 失效（404）仍是设计内行为**；设置后引用跨重启/跨实例可用；值格式非法时服务拒绝启动。**多实例部署必须设置两密钥**（两域各用独立值）。TTL 与「token 即唯一凭证」语义不变。
- 使用注意：引用 URL 用完即弃；失效后重新生成，不要缓存或收藏引用链接。

### A2. 桌面「移动报工」是引导页，不是移动报工页

桌面菜单「移动报工」打开 `/reports/mobile` 引导页；报工申报只在移动端 `/m/report`。（来源：交接文件 §三.6「设计如此非缺陷」、ui-round2 报告 §4 表第 6 行 PASS）

### A3. 采购单价按「元」填写

输入 `128.50` = 128.50 元（系统内部按分存为 12850）。不要按分填写；超大误输有预检拦截。（来源：交接文件 §四.1、ui-round2 报告 §5 抽查 PASS）

### A4. 齐套校验 fail-closed：缺料拦截装配建单；空清单不判齐套

- 装配类派工单在齐套不足时**一律拒绝**，没有绕过开关（来源：`architecture/ROLE-PACKS.md` §2 步 17）。
- 空清单执行缺口核查时**不会判「齐套」**，页面顶横幅三分支说明（来源：交接文件 §二 第 8 条 UX-PLAN-03 修复描述）。

### A5. 多级审批：未轮到本级不能批（预警 + 拒因），但按钮不硬禁用

- 多级配件链下，只有前级审完且轮到本级才能批；未到本级时移动端点击前有预警，提交被拒并给出主语化拒因。按钮不做硬禁用是设计取舍——以提交反馈为准（来源：ui-round2 报告 §3 表第 2 行 PASS/PARTIAL）。
- 链级数与角色为部署配置，缺省单级；配置错误启动即失败，不静默降级（来源：`deploy/compose.yaml` D-25 段注释）。

### A6. 登录限流是防爆破闸门：锁定期内正确口令也拒

同一账号 15 分钟窗口内失败 5 次 → 锁定 15 分钟；锁定期内**口令正确也拒绝**（防绕锁探测），429 固定文案不含用户存在性信息。成功登录清零计数。参数可由部署方用 env 调整（来源：`packages/application/src/auth/login-attempt-stores.ts` L49-51；`architecture/contracts/m2-security/CONTRACT.md` SP-1）。

### A7. 命令幂等与乐观锁：重复提交同一命令得 409

业务命令走统一信封（operationId 幂等 + expectedRevision 乐观锁）；同一 operationId 重复提交返回 409 幂等冲突，是正确防护不是故障（来源：`TESTING-GUIDE.md` §4.3）。

### A8. 菜单可见 = 接口可达；操作按钮不按角色隐藏

菜单按角色权限投影；页内按钮不做码级隐藏，无权限时提交被后端 403 拒绝（来源：`apps/web/src/menu.ts` 头注、`architecture/ROLE-PACKS.md` §0「界面级口径」）。

### A9. 多语言：中文权威、英文骨架、业务数据不翻译

- zh-CN 完整权威；en-US 是骨架（登录/主壳菜单/通用文案），模块页缺失文案**回落中文**——设计内形态（来源：ADR-0012 决定 2/5；交接文件 §五.3）。
- 语言切换在登录页右上与主壳顶栏；刷新保持（localStorage `smes.locale`）。
- 管理员自定义菜单名、用户录入名称等业务数据不翻译（来源：ADR-0012 决定 4、交接文件 §五.5）。
- 后端错误响应带语义化 `code` 字段（如 `auth.rate_limited`），中文 message 原文不变；未知 code 回落 message（来源：ADR-0012 决定 3）。

### A11. 自动联动（配置依赖）

- **末道工序报工自动生成质检单**（来源=报工）：依赖默认末道工序类型配置；部署方裁剪配置后改为质检岗手工建单（来源：ROLE-PACKS §2 注记 4）。
- **装配派工成功自动生成发料任务**（ISS-ASM- 前缀）：无需人工建单（来源：ROLE-PACKS §2 步 17）。
- **来料需检路径**：采购收货只产生入库指令，物料不进正式库存，质检判定后仓管放行入库（来源：ROLE-PACKS §2 步 8/10）。
- **缺省收货仓**：收货未显式指定仓库时按租户回落 code=`MAIN` 仓（env 可改；未配置则必须显式传仓）（来源：`deploy/compose.yaml` D-16 段、`deploy/README.md`）。

### A12. 两个「查询为空/拒绝」的设计内口径

- `GET /listing/upload-stats` 返回 409：下图统计的数据库计数面按合同归部署期接线，未接线时显式拒绝、不静默回 0（来源：TESTING-GUIDE §4.1）。
- 成本项目查询 404：成本快照须先发重建命令（跑批命令化，无数据=无快照）（来源：TESTING-GUIDE §4.2）。

### A13. 两种只读形态并存

viewer（种子，零策略全拒形态）与 observer（49 读码全读观察形态）是两种口径，用途不同（来源：`architecture/ROLE-PACKS.md` §1.7、seed-factory.mjs 头注）。见 [roles/observer.md](roles/observer.md)。

### A14. 安全响应头（CM-1）：页面不可 iframe 内嵌

服务端与 web 静态层统一返回安全响应头：CSP、`X-Content-Type-Options: nosniff`、`Referrer-Policy: strict-origin-when-cross-origin`、`X-Frame-Options: DENY`（来源：`apps/server/src/main.ts` L111-116 全局中间件 + `apps/web/nginx.conf` CM-1 段——HTML 页面权威层，双拓扑覆盖）。使用注意：页面**不能被 iframe 内嵌**（DENY 是有意设计）；通过反代/门户集成或把 API 改为跨源时须按 `deploy/README.md`「登记说明」调整 CSP，不得绕过或移除安全头。

### A15. 图纸保密许可是请求自声明（v1 无租户许可配置面）

图纸域的 clearance（保密许可）目前由调用方/页面**自行声明**（图纸库与工作令图纸卡的「保密许可（自声明）」选择器；接口为显式请求参数）——系统按声明的许可执行修订与**变更通知**的可见性过滤（M2-R1 起 `/drawing/notices` 同口径）并保留 `drawing:read` 权限门，但**不校验声明值与账号真实身份的对应关系**：持有 `drawing:read` 的账号声明更高许可即可读到相应受限内容。真实身份↔保密等级的绑定（租户许可配置面）为待裁定项（原图纸合同 P2-3／O5）。在此裁定落地前，受限图纸的分发控制依赖使用者如实声明与部署层访问边界；公网/多客户环境部署时须把该边界计入威胁模型。（来源：`apps/server/src/drawing-http.module.ts` 头注「v1 无租户权限配置面」；M2-R1 裁-12 交付限定；PM 2026-10-28 产品接收裁定）
