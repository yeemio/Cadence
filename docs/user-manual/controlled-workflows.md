# 当前操作：排程放行、采购批准与质量库存

更新日 2026-10-31，适用于产品源码 `0425ded`。新内部派工、新采购订单和采购质量库存按本页交接；原岗位手册保留各自的日常操作。已有单据状态不代表已经补齐当前审批，不能用重跑演示种子替代放行。

## 1. 谁来操作

## 2. 新内部派工：草案 → 联合排程 → 运营放行 → 开工

1. 生产岗在 `/dispatches` 创建内部派工草稿，核对工作令、工序和数量。装配/电气派工还须关联本工作令的真实设备，清单设备关联及齐套前置须已满足。此时没有生产放行。
2. 计划 E07 进入制造控制台「联合排程」，选择「实际内部派工」、有效「生产机台」、启用的「工装」、「操作人员」，填写开始/结束时刻和原因，点「保存排程草案」。**草案不占用正式资源**。
3. 工程 E05 核对该操作人员在这道实际工序的有效技能资格；缺少时在同页填写人员、工序、有效至及依据，点「记录工序技能资格」。资格有效期须覆盖排程结束时刻。缺机台、工装或人员主数据时，先交管理员维护，不能填虚构资源。
4. 运营 E02 在同页「当前单据与历史」选中该草案，点「批准生产放行」。系统同时校验机台、工装、人员时窗冲突、技能、故障和工程版本。成功后排程为「已批准」，源派工从草稿变为「已派工」，执行人取批准排程中的人员。
5. 生产岗回 `/dispatches` 核对派工状态与人员，再点「开工」；执行中按原移动报工入口提交。开工、报工及后续发料仍受有效排程、故障封锁和工程冻结约束，曾获批准不等于永久放行。

原「派工到人」/批量指派入口不能绕过联合排程。被拒时把派工编号和原因交计划/运营：资源冲突须调整时段或资源；尚未执行的有效排程先取消再改排；缺技能交工程。执行中排程不能通过取消抹去，转单也不能把人员改成与批准排程不符的人。故障维修完成后，仍须运营 E02 与品质 E10 在「复机会签」分别签署本次维修版本，才可恢复；新故障使旧签名失效。工程冻结或旧版派工拒绝时交工程/运营处理，不反复点开工。

2026-11-03 转单一致性修复候选补充：转单目标工序也必须与有效批准排程一致；把已批准工序 A 改为 B 会在写派工和事件前被拒绝，原派工、排程和报工路径保留。保持批准工序、转回批准人员的合法操作仍可执行。当前没有执行中的重新排程批准模型；确需换工序时交计划/运营处理，不通过转单修改已批准工序。

工厂种子中的执行中单仅是既有在制示例；本版不因其状态自动补排程，也不能承诺它可直接继续报工。完整演示请新建草稿并走上述步骤。若要演示末道自动建检，使用实际末道 `DWG-001 × OP-005`；种子 `OP-001` 不是末道。

## 3. 新采购：建单 → 明确净价 → 财务复核 → 分级批准 → 下发

1. 采购在 `/purchase/requests` 准备申请，在 `/purchase/orders` 建单并提交；核对实际工作令、供应商、物料、数量、交期和关联申请。订单进入「已提交」，**还未获准下发**。采购订单原单价表单以元填写；下一步制造控制台的净单价字段以**分**填写。
2. 采购 E08 打开制造控制台「采购净额」，选「实际采购订单」，逐行填「明确净单价（分，不自动推算）」和依据，点「提交本版净价」。原含税价保持原值；空净价不按零计算，也不从含税价自动反推。
3. 财务 E13 核对真实需求来源。通过清单来源关联的需求保留原关联；手工来源没有真实需求关联时，在同页选择订单行及已核定需求，或据实核定新需求，点「财务核定需求关联」。同一需求跨订单、供应商累计，不能通过拆单或另填分组逃避累计。同需求的历史/在途净额不明时，须先核查并补齐有依据的历史净额核定或更新在途报价，不能忽略或按零处理。
4. 财务 E13 在「当前单据与历史」选本版净价记录，填依据，点「独立财务复核」。成功显示「已复核待批准」、本单净额和所需批准职责。复核人须与采购发起人/报价人不同。
5. 按当前结果由运营 E02 或总经理 E01 选择记录，点「按当前累计阈值批准」：**本单总净额或任一同需求累计净额超过 100,000 元须 E01；均不超过时由 E02 批准**。批准人不得是该单发起人、报价人或复核人。成功后制造记录和源采购订单均为已批准状态。
6. 采购回 `/purchase/orders` 核对同一订单，再点「下发订单」。若 PO 行、价格、来源或同需求累计发生变化，旧复核/批准会失效，按页面原因返回当前版本重新复核和批准；不要改走旧「审批通过」按钮。旧批准入口会拒绝直接放行。

已有已发/已收货订单按真实历史事实继续核对，不重新报价以改写过去。财务「补记历史净额核定（不改旧单）」只补其净额依据，不代表新订单已走完复核批准，也不提供 PO 业务 A/B 版或应付管理。

## 4. 收货、质检与发料：分别核对实物和质量

库存页 `/inventory/stock` 区分「物理总量、待检、合格、隔离、未知、有效占用、合格可用」。**物理总量 = 待检 + 合格 + 隔离 + 未知；合格可用 = 合格减有效占用，最低为零。** 待检、隔离、未知不能当合格可用量。旧无证余额不会自动变为合格；品质只能依据真实记录核对，不能为凑齐套随意认定。

| 动作与负责人 | 怎么做、交给谁 | 应核对的结果 |
| --- | --- | --- |
| 采购实收，仓管 | `/purchase/receiving` 选择已下发订单、行、实收数量、收货单号及仓库；保存后把收货来源和待检单号交质检 | 首次实收增加物理在手量，进入待检。合法可分类采购来源自动建检；回执没有待检单号时按其未建检原因核查，不能默认所有手工/旧种子订单都会建检 |
| 来料判定，质检 | `/inspections` 核对同一收货来源、物料及数量，填写合格/不合格数量；缺实际物料时先选择「放行物料」 | 记录质量结论，不自动增加合格库存；不合格量进入隔离。把有效合格放行及余量交仓管 |
| 消费采购放行，仓管 | `/inventory/stock-operations` 的入库表单选「质检放行」，选本次放行单及物料，使用原收货批次所在仓、数量不超过有效余量 | 同批待检量转合格，**物理总量不变**，不能再次增加实物量；可以在余量内分批。不同来源/仓库不能拿来补放行 |
| 报工末道等尚未实物入仓来源，仓管 | 核对真实来源与有效质检放行后，从同一「质检放行」表单办理首次物理入库 | 此时才增加物理总量及对应合格量；仍受物料、放行额度、工程版本与跨仓累计约束，与采购实收后的质量释放不同 |

仓管已消费过的判定不能直接撤销；超放行余量、已耗尽、物料不符或冻结时按拒因交回质检/工程核查，不能另建无来源单补账。生产与品质不代仓管执行入库，仓管不代质检改判。

装配/电气派工按本工作令真实设备和设备维清单建草稿，经排程批准使派工真正指派后，才同步相应发料任务；仅建草稿不代表任务已生成。外购设备归拢须明确选择，按类别读回实际任务。发料任务目前没有独立桌面页，由有权仓管经实施方提供的现有接口确认/整单撤销；不能把通用「出库」表单当作任务确认的替代。

| 发料类别 | 确认后的结果 | 撤销后的结果 |
| --- | --- | --- |
| 零件 `part` | 记录设备维预占来源拆分与发料事实，不直接扣实时库存 | 原发料记录转为撤销，退出已发累计，按原来源快照恢复任务可发口径；不是一笔库存入库 |
| 外购设备 `equipment` | 记录归拢发料及来源快照，不直接扣实时库存 | 原记录退出有效发料累计；不凭空增加库存 |
| 标准件/电气件 `standard` / `electrical` | 必须选择真实库位；按合格来源扣减现存量并核销对应设备预占，不能发待检/隔离/未知余额 | 按原记录的真实库位、批次和预占来源恢复，保留原流水与撤销记录 |

一次发料记录只处理一种类别；缺库位的标准/电气行不能当作已发。判断是否完成须同时查看任务、有效发料记录及相应库存/流水，不能用统一的“库存下降”判断所有类别。完整领退料业务单据状态机仍未纳入本版。
