# Cadence 用户手册（入口）

读者：未参与开发的使用者——按岗位使用系统的操作人员、管理员，以及做安装与演示交接的实施人员。
本手册说明：每个岗位能做什么、怎么操作、预期看到什么、被拒绝时怎么办；当前版本的限制与故障处理见 [KNOWN-BEHAVIORS.md](KNOWN-BEHAVIORS.md)。

口径声明（读手册前必读）：

- 本手册描述**当前版本的实际行为**，原快照日 **2026-10-27**；2026-10-31 已按产品 `0425ded` 对齐排程、采购审批与质量库存操作。界面文案、菜单结构、账号以你手上系统的实态为准；发现与手册不一致时，先查 [KNOWN-BEHAVIORS.md](KNOWN-BEHAVIORS.md) 是否已登记为设计内行为或已知限制。
- 手册不承诺「一键安装成功」。安装与部署步骤见 [../deploy/README.md](../../deploy/README.md)，安装验收是独立环节。
- 每节关键事实在文内标注来源文件（仓库内路径）。本手册不复制需求规格全文；想知道「产品应该是什么」以 `architecture/requirements/`（PRD v1.0）为准。

## 2. 业务旅程总图（岗位在链上的位置）

核心业务链沿原岗位交接，并按[当前操作](controlled-workflows.md)补齐已接受的制造控制：

```
计划：建令 → 清单 → 缺口核查
  │
采购：申请/建单 → E08净价 → E13独立财务复核 → E02/E01分级批准 → 采购下发
  │
仓管实收（物理量先入待检）→ 质检判定 → 仓管消费放行（同批待检转合格，实物不再增加）
  │
计划齐套复核 → 生产建派工草稿 → E07联合排程 → E02批准 → 生产开工/报工
  │                                                         │
装配/电气真正指派后同步设备发料任务                    末道自动建检 → 质检 → 仓管首次入仓
  │
仓管按类别确认发料（零件/设备记录发料；标准/电气按真实库位扣减及核销）
  │
配件申请（计划）→ 原项目经理/配置多级审批 → 计划发货联动出库
  │
只读观察岗：在已授予读取范围内查看，不能提交
```

各步的前置条件、操作入口、预期结果与交接去向，见 [journey-core-chain.md](journey-core-chain.md) 的逐步表。

## 3. 岗位与权限的基本规则

1. **菜单可见 = 接口可达**：左侧菜单按你的角色权限投影；看不到某菜单项，说明该角色未被授予对应权限，而不是系统故障（来源：`apps/web/src/menu.ts` 头注、`architecture/ROLE-PACKS.md` §0）。
2. **防线在后端**：原业务页部分按钮仍可见但无权提交；制造控制台另按制造职责显示动作。无权限时提交会被后端拒绝（403 / 错误提示）。看到报错先确认自己角色是否有该动作权限（来源：`architecture/ROLE-PACKS.md` §0「界面级口径」）。
3. **按职责交接**：原七岗位包与新增制造职责分开授权，不能因菜单可见就代另一职责审批。采购发起/报价、财务复核、批准须由不同自然用户承担；判定与仓管执行分离。演示 plan01 兼任夹具工作令项目经理的配件审批例外见[审批岗](roles/approver.md)，不能照搬为采购自批。
4. 全员基线：所有角色都有工作台入口与顶栏通知中心两个只读权限（来源：`architecture/ROLE-PACKS.md` §1「全员基线两码」）。
