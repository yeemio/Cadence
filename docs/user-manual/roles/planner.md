# 计划岗（planner）操作手册

事实快照日 2026-10-27（同日 M2-R1 增量后更新：工作令可搜索选择与上下文跳转、缺口核查汇总口径修正）。来源：`architecture/ROLE-PACKS.md` §1.1（权限码与页面入口均经实态取证）；菜单与按钮名以系统实态为准。

## 职责

从工作令下发起，管清单展开、库存缺口核查与齐套，是业务链的发起端与装配发料的触发端。计划只建令，不管工作令的九态流转与关令（那是管理岗终裁权）。

## 权限与菜单入口（13 码：全员基线 2 + 岗位 11）

| 能做什么 | 菜单入口 | 说明 |
| --- | --- | --- |
| 看工作台/通知 | 工作台 `/`、顶栏铃铛 | 全员基线 |
| 查工作令、建令、改令、挂附件 | 制造运营 → 工作令 `/workorders` | 建令是本岗核心动作；建令即自动生成四类清单骨架 |
| 查四类清单、骨架导入、Excel 导入、修订行 | 清单 `/listings/sheets`；或工作令页行内「清单」直达 | 骨架导入 = 按工作令建四类空清单；工作令可搜索选择（M2-R1），不再需要手工查找/复制内部 id |
| 执行缺口核查 | 缺口核查 `/listings/gap-checks`；或工作令页行内「缺口核查」直达 | 利库核查核心动作；同上支持可搜索选择与带单跳转 |
| 看齐套看板、刷新齐套检查 | 工作令详情内嵌 | 「刷新齐套检查」按钮 |
| 查物品台账 | 基础数据 → 物品 `/masterdata/items` | 清单行物料核对用（只读） |
| 配件申请发起与发货 | 配件申请 `/workorders/parts` | 含「发货（联动出库）」按钮 |

**明确没有**：工作令九态流转/关令、图纸域、采购链后续动作（申请发出后归采购岗）。

## 典型日操作

1. **建令**：工作令页 →「创建工作令」→ 填项目名（必填；建议含年份编号便于检索）、可选客户引用/计划交付日期/项目经理/销售 → 提交。
   - 注意：项目经理/销售字段若留空，后续配件审批走「回落」规则（一级审批人回落到销售，两者都空则审批链无人——表单会提前提示「审批将无人处理」，此时应先补主数据或换人建令）。
2. **清单**：清单页 → 工作令输入框从候选列表选择（按项目名辨认，也可直接粘贴工作令编号）→「查询清单」（骨架缺失时「骨架导入（建四类空清单）」）→ 选中行修订数量/需求日期 →「修订行」。清单为空时可「新增清单行」。也可以在工作令页选中某单后点行内「清单」直接带单过来（页面会显示所选工作令的项目名与短码供确认）。
3. **缺口核查**：缺口核查页 → 同上选择工作令 →「执行缺口核查」→ 读最新快照。每次核查生成一条不可变快照，可对照历史；工作令页行内「缺口核查」可直达。换了工作令后页面不会沿用上一单的核查结果。
4. **齐套**：工作令详情 →「刷新齐套检查」→ 在齐套看板看「齐套完成/缺口行」三类清单 × 库存下钻。
5. **配件申请**：配件申请页 →「新建配件申请」（工作令编号 + 物料 + 数量）→ 提交即进入待审批；审批通过后回本页选中该申请 →「发货（联动出库）」。

## 常见拒绝与恢复

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 建装配派工单被拦截（在生产岗执行时本岗可从齐套看板预判） | 齐套校验 fail-closed：缺料一律拒绝，无绕过开关 | 等缺口物料入库后让生产重试；或先在缺口核查确认缺口已收敛 |
| 工作令候选列表不出来 | 候选来自工作令列表接口；权限不足或无数据时输入框自动退回手填模式 | 直接粘贴工作令编号（与候选选择等效）；权限问题找管理员核对 |
| 「修订行」后行的物料校验状态变「待校验」 | 物料三要素变化会重置校验态（设计内） | 等待/触发重新校验；核对物品台账编码一致 |
| 建令提示审批无人处理 | 项目经理与销售都为空 | 先让管理员维护对应主数据，或填写其中一个 |
| 菜单里看不到缺口核查/配件申请 | 角色权限未配齐 | 找管理员按本页权限表核对（角色授权 diff 见 [admin.md](admin.md)） |
