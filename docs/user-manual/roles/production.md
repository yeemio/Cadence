# 生产岗（production）操作手册

事实快照日 2026-10-27。来源：`architecture/ROLE-PACKS.md` §1.3；菜单与按钮名以系统实态为准。

## 职责

车间执行端：六类派工建单与调度、按单报工申报数量与工时、执行中转单换人、现场故障上报。报工的核查/审核/冲销归核查链（七岗位包外），本岗提交后不能自己改判。

## 权限与菜单入口（11 码：基线 2 + 岗位 9）

| 能做什么 | 菜单入口 | 说明 |
| --- | --- | --- |
| 查派工单 | 派工 `/dispatches` | 六类列表筛选、按人任务视图 |
| 建派工单、开工、完工 | 「创建派工单」「开工」「完工」按钮 | 建单含齐套拦截；四态：草稿→已派工→执行中→（完工） |
| 派工到人、转单、批量指派 | 「派工到人」「转单（仅执行中）」按钮 | 转单仅「执行中」状态可用 |
| 撤销草稿/已派工单 | 「撤销」按钮 + 批量取消 | 仅草稿/已派工两态可撤 |
| 移动报工 | 移动端 `/m/report`「提交」 | 桌面「报工单」页 `/reports` 只查不报（申报走移动端） |
| 查报工单、查工时 | 报工单 `/reports`；成本与工时 → 工时统计 `/hours/stats`；移动端同径 | 查本人与五类列表 |
| 扫码 | 扫码 `/scan` | 报工的数据采集前置 |
| 移动故障上报 | 移动端 `/m` 报故障 | 上报动作；故障查看页需另行授权才可见 |

**明确没有**：报工核查/审核/撤销、质检判定、入库。

## 典型日操作

1. **建派工单**：派工页 →「创建派工单」→ 选类型；零件单填图号+工序+数量（必填）→ 提交。备注可填；工作令/人员候选列表在你无对应查询权限时会静默降级为手工输入（设计内）。
2. **派工**：列表或详情 → 填执行人 →「派工到人」→ 执行人收到工作台待办 → 点「开工」。
3. **报工**：移动端 `/m/report` → 扫码定位派工单 → 填完工数量 + 工时分钟 →「提交」。**末道工序的报工会自动生成一张质检单**（来源=报工），质检岗随后判定。离线提交会进入本地队列，联网后上行（以系统实态为准）。
4. **转单**：详情页填新执行人/新工序 →「转单（仅执行中）」→ 留痕换人。
5. **完工**：详情页「完工」（填完工数量）。
6. 收尾查自己的报工单与工时统计；设备异常走移动端故障上报。

## 常见拒绝与恢复

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 建装配类派工单被拦截 | 齐套校验 fail-closed：缺料拒绝建单（设计内闸门） | 通知计划岗确认齐套（刷新齐套检查）、补料后再建 |
| 建单提示同图号×工序占用 | 同图号同工序已有在制派工单，互斥拦截（设计内正确行为，来源：`architecture/status.md` DP-05 登记段） | 先完成/撤销在制单，或换工序号 |
| 「转单」按钮不可用/拒绝 | 仅「执行中」状态可转单 | 草稿/已派工态直接改派工执行人即可 |
| 撤销按钮对执行中单不可用 | 撤销仅支持草稿/已派工两态 | 执行中的单走转单换人；不能撤销 |
| 桌面找不到报工提交入口 | 桌面「移动报工」菜单是引导页（`/reports/mobile`），申报只在移动端 `/m/report`（设计内形态） | 用手机/PWA 打开 `/m`，或直接访问 `/m/report` |
| 移动端页面打开是只读/无表单 | 当前账号无 `report:submit` 权限（如 viewer/viewer 形态账号） | 换生产岗账号 |
| 报工后要改数量 | 提交后单据进入核查链，本岗不能修改 | 联系核查链岗位（管理员或按 ROLE-PACKS 注记补权者）走修正/冲销 |
| 派工详情里个别时间显示 UTC 原始格式 | 已登记差异（部分页面时间未本地化） | 以系统实态为准；见 KNOWN-BEHAVIORS |
