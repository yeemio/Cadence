# 仓管岗（storekeeper）操作手册

原快照日 2026-10-27；2026-10-31 对齐当前质量库存与分类发料，详见[当前操作第 4 节](../controlled-workflows.md#4-收货质检与发料分别核对实物和质量)。来源：`architecture/ROLE-PACKS.md` §1.5；菜单与按钮名以系统实态为准。

## 职责

库存账的执行者：三类入库（完工/质检放行/采购收货）、发料与领用出库、调拨移库、盘点调账、发货执行、仓库与货架维护。判定归质检岗——仓管只按质检放行事实入仓，不判合格与否。

## 权限与菜单入口（17 码：基线 2 + 岗位 15）

| 能做什么 | 菜单入口 | 说明 |
| --- | --- | --- |
| 建仓、配库位、货架维护、查目录 | 仓储管理 → 仓库与库位 `/inventory/warehouses` | 四级货架结构；仓库当前无「启停」概念（已登记限制） |
| 查库存/流水 | 实时库存 `/inventory/stock`；收发存操作 `/inventory/stock-operations`；移动端查料 | 同看物理总量、待检、合格、隔离、未知、有效占用与合格可用，不把物理在手量当可发量 |
| 三类入库 | 收发存操作页「入库」表单；移动端入库 | 完工 / 质检放行（必填质检单号）/ 采购收货（必填收货单号） |
| 出库 | 「出库」表单 | 目的=生产/配件/手工；预占键可选（直扣或核销） |
| 调拨/移库 | 「调拨 / 移库」表单；移动端移库 | 源/目的仓库库位；调拨成功回显两腿流水号 |

## 典型日操作

1. **入库**：收发存操作页「入库」表单 → 选来源 → 填物料/仓库/数量 →
   - 来源=质检放行：**质检单编号必填**（可分批入仓，受放行余量约束）；
   - 来源=采购收货：收货单号（receiptKey）必填；
   - 来源=完工：完工件入仓。
   - 按来源读回：采购收货首次增加物理量并计待检；对已实收采购批次消费质检放行只把同批待检转合格，物理总量不再增加。尚未入仓的报工末道等来源首次入库才增加物理量。放行必须匹配原来源、物料、仓库及有效余量；不能一律期待现存量上涨。
2. **通用出库**：「出库」表单填写目的及适用预占键后执行，须有合法合格可用来源。装配/电气设备发料任务走第7步，不能用通用出库代替；配件申请发货由其原联动动作处理。
3. **调拨/移库**：「调拨 / 移库」表单 → 源/目的仓库库位 →「执行调拨」→ 流水号回显（两腿以顿号分隔）。
4. **盘点**：盘点页「开盘点单」（仓库编号）→ 逐物料「录入实盘」→ 提交差异（complete）→「审核调账」（理由必填）→ 调账留痕。
5. **发货**：发货任务页「建发货任务并执行」（物料/数量/承运/运单号）→ 详情「确认发货」→ 确认后联动对应工作令进入「已发货」。
6. **采购实收**：从 `/purchase/receiving` 选择已下发订单、行、实收数量、收货单号及仓库；本岗无需读取完整 PO 价格/审批。实物先增加待检库存，按回执待检单号或未建检原因交质检；后续消费放行不再增加物理总量。
7. **发料确认**：按真实设备建装配/电气草稿，经联合排程批准使源派工真正指派后同步任务；外购设备归拢须明确选择。由有权仓管经实施方协助走现有接口，一次记录一种类别。part/equipment 保存来源快照和发料事实，不直接扣实时库存；standard/electrical 选择真实库位，按合格来源扣减并核销设备预占，撤销按原批次/库位/预占恢复。详见[分类结果表](../controlled-workflows.md#4-收货质检与发料分别核对实物和质量)，须同时查任务、有效记录及库存流水。
8. 移动端：入库 / 移库 / 盘点 / 查料 四个子页同径操作。

## 常见拒绝与恢复

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 质检放行入库被拒「缺质检单号」 | 必填校验（放行事实可溯，设计内） | 到质检队列找到对应质检单编号填入 |
| 入库数量被拒 | 超过质检放行余量 | 余量内分批入库；不足部分确认质检判定数 |
| 找不到发料任务页面 | D-IS-01：issue 域无桌面页（已登记限制） | 请实施方协助走现有接口，按类别核对任务、记录和库存；part/equipment不直接扣库存 |
| 调账被拒 | 审核调账理由必填 | 补理由提交 |
| 想停用某个仓库 | 仓库级启停概念未实现（已登记限制 WH-05） | 用命名/库位管理规避；见 KNOWN-BEHAVIORS |
| 质检合格后可用量仍未增加 | 判定不自动将采购待检转合格；待仓管消费有效放行，且已有占用会减少可用量 | 核对同批放行余量与有效占用；采购释放后物理量保持不变，不重复收货补量 |
| 货架/库位落位失败 | 落位解析按货架层级保护规则（四级） | 核对库位层级与容量；按「仓库与库位」页实态调整 |
