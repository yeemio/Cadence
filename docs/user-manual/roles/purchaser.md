# 采购岗（purchaser）操作手册

原快照日 2026-10-27；2026-10-31 对齐净价、财务复核与分级批准，详见[当前采购流程](../controlled-workflows.md#3-新采购建单--明确净价--财务复核--分级批准--下发)。来源：`architecture/ROLE-PACKS.md` §1.2；菜单与按钮名以系统实态为准。

## 职责

把缺口变成订单：从缺口或手工发起采购申请，建单、提交、跟进下发与收货，办理退货。新订单由采购 E08 明确净价、财务 E13 独立复核，再交运营 E02/总经理 E01 分级批准（发起/报价、复核和批准须不同自然用户）；供应商等主数据维护归管理员/主数据岗。

## 权限与菜单入口（9 码：基线 2 + 岗位 7）

| 能做什么 | 菜单入口 | 说明 |
| --- | --- | --- |
| 查采购四页（申请/订单/退货/明细） | 采购管理 组 | 状态过滤：申请 draft/approved/converted；订单五态 |
| 发起采购申请 | 采购申请页「提交采购申请」 | 从缺口或手工发起 |
| 建单并提交、下发订单 | 采购订单页 | 承接申请；下发/逾期扫描 |
| 收货入库 | 订单页「收货入库」按钮；菜单叶子「采购收货」`/purchase/receiving` | 录行号/数量/收货单号；与仓管岗共码（小厂双人经办口径） |
| 建退货单/撤销退货 | 采购退货 `/purchase/returns` | 针对已收货订单 |
| 查供应商、查物品 | 基础数据 → 供应商 / 物品 | 建单需供应商引用；只读 |

**职责边界**：原采购权限不自动包含制造 E08；需要净价操作时由对应 E08 人员接续。新订单审批不再走旧 `purchase:approve` 按钮，见[审批岗](approver.md)；缺口核查和供应商维护仍交原责任岗。

## 典型日操作

1. **发起申请**：采购申请页 →「手工发起采购申请」→ 选类别、物料、数量（可挂工作令）→ 提交。计划岗缺口核查产生的缺口行是本步的常见输入。
2. **建单**：采购订单页 →「建单并提交采购订单」→ 填供应商引用/名称、**交期（必填，ISO 日期格式）**、至少一行物料+数量、备注与关联配件申请（如有）→ 提交。订单进入「已提交」，随后交采购 E08 在制造控制台逐行提交净价（以分输入）及依据，财务 E13 核定必要的真实需求关联并独立复核，再由页面要求的 E02/E01 批准。
3. **批准与下发**：按[当前采购步骤](../controlled-workflows.md#3-新采购建单--明确净价--财务复核--分级批准--下发)完成复核批准后，回订单页核对源单已审批再下发。净价/PO/同需求累计变动可能使旧批准失效；按拒因回财务复核，不点旧审批按钮绕过。下发后按订单状态和逾期待办跟催。
4. **收货**：已下发订单到货后，从「采购收货」`/purchase/receiving` 选订单、行、数量、收货单号及仓库。物理量先计待检，按回执待检单号交质检；合格判定后由仓管消费放行，实物不重复增加，见[质量库存](../controlled-workflows.md#4-收货质检与发料分别核对实物和质量)。
5. **退货**：退货页对已收货订单建退货单；撤销退货同页。

## 常见拒绝与恢复

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 建单时交期校验失败 | 交期必填且为标准日期格式 | 按页面提示格式填写 |
| 旧「审批通过」或未复核下发被拒 | 当前采购必须经过制造控制台的明确净价、独立复核和分级批准 | 按当前采购流程交 E08/E13/E02或E01；不通过临时加旧审批权绕过 |
| 收货仓库不明确 | 收货表单已提供仓库选择 | 选择实际收货仓，质量释放也须核对该批所在仓 |
| 关联申请不正确 | 当前建单支持多选已有申请；错误来源影响真实需求累计和自动建检 | 选择同一工作令/物料的真实申请；缺真实需求关联交财务核定 |
| 对已收货订单重复收货 | 行收货数量受订单行数量约束 | 按剩余量收货；多退少补走退货 |
| 单价填错量级 | 采购订单原单价按**元**填写；制造控制台明确净单价按**分**填写（128.50元对应12850分），二者不能混用 | 见 [../getting-started.md](../getting-started.md) 通用约定 |
| 单号很长显示为「头8…尾4」 | 短码显示约定 | 引用给他人时注意复制得到的是短码（已知使用注意，见 KNOWN-BEHAVIORS） |
